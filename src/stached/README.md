# Stached (UI)

The game's front end: login, home screen, a day's board, stache clock, past games, leaderboard, and dialogs. The page, `src/pages/Stached.tsx`, holds the session (`session.ts`), and each screen is a route inside it.

How the whole game works (the API, puzzles, deploying, migrations, backups, and the Studio and Cloudflare setup) is in [`stached-api/README.md`](../../stached-api/README.md).
